# وسيط القانوني والقضائي

منصة وسيط الرقمية للمحاماة والقضاء في اليمن.

## المكونات

- الصفحة الرئيسية
- إنشاء حساب
- تسجيل الدخول
- محامي
- محامي تحت التدريب
- قاضٍ / محكم
- عميل
- الصفحة المهنية
- صحيفة الجلسات
- بوابة المحامين
- منصة القضاة والمحكمين
- الدعم الذكي

## ملاحظة مهمة

هذه النسخة Front-End.

الحسابات يتم حفظها محليًا في المتصفح باستخدام localStorage.

لتحويل المنصة إلى نظام حقيقي متعدد المستخدمين، يجب إضافة:

- Backend
- قاعدة بيانات
- نظام مصادقة حقيقي
- تشفير كلمات المرور
- صلاحيات المستخدمين
- API
- رفع ملفات آمن
- تخزين مستندات
- نظام OTP حقيقي
- نظام إشعارات
- نظام دفع
- حماية للبيانات القانونية
